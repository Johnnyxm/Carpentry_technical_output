# Listellini assemblaggio telaio — Frassino

Semilavorati di recupero usati nell'assemblaggio del telaio Wooden Dummy.

- dimensione nominale: **500×27×25 mm**;
- fabbisogno: **2 pezzi per telaio**;
- origine: sfridi/by-product compatibili di frassino spessore 25 mm;
- non consumare listelli finiti conformi 1300×56×25 mm quando sono disponibili sfridi compatibili;
- la quantità richiesta dalla Run è un minimo: ulteriori pezzi conformi possono essere prodotti per recuperare sfridi e messi a stock.
