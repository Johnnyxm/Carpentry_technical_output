# DT-DIMENSIONI-001 — Distanziale telaio

**Revisione corrente:** A

## Specifica
- materiale: frassino;
- dimensioni nominali definitive: **80×25×25 mm**;
- sezione: **25×25 mm**;
- origine: sfridi/by-product compatibili di frassino.

La precedente specifica 80×20–30×25 mm è superata: la sezione canonica è **25×25 mm**.

## Quantità
4 pezzi/telaio. Il fabbisogno Run è un minimo, non un limite di batch: gli sfridi compatibili possono essere trasformati in pezzi aggiuntivi conformi e messi a stock.
